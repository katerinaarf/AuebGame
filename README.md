# platform game

## Computer Programming with C++ - AUEB Assignment

This is a 2D platformer game developed in C++ as part of the C++ Programming course. The game uses the SGG (Simple Graphics Library) provided by our professor to handle graphics and rendering.

##Features:
Classic platformer mechanics (jumping, moving, etc.)
Multiple levels with increasing difficulty
Collision detection and physics
Simple 2D animations and effects

##Technologies:
C++: Core programming language
SGG (Simple Graphics Library): Custom library used for graphics rendering and game loop management

##Purpose:
The goal of this project is to apply object-oriented programming concepts and improve my understanding of game development using C++.
